# Gallery 2.1.7 — колонки для телефонов, планшетов и компьютеров

Полноценное обновление дополнения Content Gallery для TZ Portfolio 4.1+.
Установочный архив: `gallery_content_addon_v2.1.7_responsive_columns.zip`.
Устанавливать поверх текущей Gallery через **TZ Portfolio → Дополнения →
Загрузить / Установить**. Это не компонент Joomla и не дополнение Flipbook.
Удалять старую Gallery перед установкой не требуется. После обновления страницы
админки и сайта обновите через Ctrl+F5.

В настройках Gallery добавлены три списка от **1 до 10**:

- Колонок — телефоны: ширина окна до 767 px, по умолчанию 1.
- Колонок — планшеты: 768–1199 px, по умолчанию 2.
- Колонок — компьютеры: от 1200 px, по умолчанию 3.

В редакторе материала: **Параметры просмотра материала → Параметры содержимого
галереи → Настройки колонок**. Режим **«По умолчанию»** берёт три значения
непосредственно из настроек дополнения. Режим **«Пользовательские»** показывает
три таких же списка и применяется только к этой статье. После возврата к общим
настройкам сохранённые ранее пользовательские значения не влияют на вывод.
При отсутствии новых параметров используются 1/2/3; некорректные значения также
заменяются безопасными значениями для соответствующего размера экрана.

Колонки меняются при изменении ширины окна без перезагрузки. Это пороги ширины
окна браузера, а не распознавание модели устройства. Работают в типах Сетка,
Кладка, Горизонтальная кладка и Карусель. Число колонок имеет приоритет над старой
шириной изображения. Горизонтальная кладка при фиксированном числе колонок
использует равные ячейки заданной высоты; автоматической разной ширины ячеек нет.
Для карусели старое единственное поле количества заменено тремя адаптивными.

Обновление не переносит фотографии, не меняет их подписи или порядок и не меняет
тип медиа в статьях. Выбор Галерея/Флипбук, поддержка трёх каталогов изображений
и формат данных версии 2.1.6 сохранены. ZIP содержит только код, стили, скрипты
и языковые ресурсы, без изображений, данных сайта или тестовых фикстур.

Проверено на Joomla **5.4.10 и 6.2.0**, PHP 8.4.27, TZ Portfolio 4.1.2.
На Joomla 6 плагин обратной совместимости отключён. Проверены штатная установка
через менеджер дополнений, сохранение полей в админке, реальные колонки на сайте,
пользовательские настройки и возврат к общим, границы 767/768 и 1199/1200 px,
все четыре типа галереи, подписи и открытие Fancybox без ошибок JavaScript.

Исходники этого каталога соответствуют ZIP. Сборка: `python gallery-addon/package.py`.
Тест: `tests/gallery/columns.cjs`; он использует только изолированные локальные
Joomla и охраняемые PHP-фикстуры. Для Joomla 6 задаются TZMT_TEST_BASE и
TZMT_TEST_CONTAINER; охрана PHP-фикстуры дополнительно требует префикс joom_
и маркер `/tmp/tzmt-j62-fixtures-authorized`.
