# Совместимость компонента переноса 1.0.5 с Joomla 6.2

Проверен исходный установочный архив `com_tz_media_transfer_v1.0.5.zip`.
Изменять код или выпускать новый архив для Joomla 6.2 не потребовалось.

## Проверенная конфигурация

- Joomla 6.2.0, стандартная административная панель Atum.
- PHP 8.4.27, MariaDB 11.4, TZ Portfolio 4.1.2.
- Плагин `behaviour/compat6` **отключён**.
- Полный движок и новый поиск повторно проверены при `error_reporting = maximum`.
  Исходная настройка возвращена после проверки.

Проверка относится к указанным установленным версиям. Будущие версии Joomla/PHP
в этом прогоне не запускались.

Прогнаны `inventory.cjs`, `engine.cjs`, `ui.cjs`, `cancel.cjs`, `failures.cjs`,
`smoke.cjs`. В режиме максимального отчёта об ошибках повторены `inventory.cjs`
и `engine.cjs`: ответы API остаются валидным JSON, проверки проходят.

Тестовые материалы: отдельные ID 91001–91008, включая корзину, отсутствующий
файл и небезопасное имя. Чистая установка выполнялась только на локальном стенде;
перед ней сохранены и затем восстановлены его журнал и резервные файлы компонента.
Контрольный хеш таблиц материалов/данных дополнений Portfolio до и после установки
совпадает. Рабочий сайт пользователя не изменялся.

## Повторение на подготовленном локальном стенде

Не запускать создание тестовых материалов на рабочем сайте.
Стенд: контейнер `tz412-web-1`, база с префиксом `joom_`, Joomla 6.2.0,
Portfolio 4.1.2 и базовый тестовый материал ID 5, доступ `127.0.0.1:8082`.
Установить 1.0.5 штатным установщиком Joomla. Затем:

```bash
python tests/media-transfer/prepare-joomla62.py /tmp/tzmt-j62-tests
docker exec tz412-web-1 touch /tmp/tzmt-j62-fixtures-authorized
docker cp /tmp/tzmt-j62-tests/fixtures.php tz412-web-1:/tmp/tzmt-fixtures.php
docker cp /tmp/tzmt-j62-tests/inspect.php tz412-web-1:/tmp/tzmt-inspect.php
docker cp /tmp/tzmt-j62-tests/failures.php tz412-web-1:/tmp/tzmt-failures.php
docker cp /tmp/tzmt-j62-tests/inventory-file.php tz412-web-1:/tmp/tzmt-inventory-file.php
docker exec --user www-data tz412-web-1 php /tmp/tzmt-fixtures.php
TZMT_TEST_BASE=http://127.0.0.1:8082 node /tmp/tzmt-j62-tests/inventory.cjs
TZMT_TEST_BASE=http://127.0.0.1:8082 node /tmp/tzmt-j62-tests/engine.cjs
TZMT_TEST_BASE=http://127.0.0.1:8082 node /tmp/tzmt-j62-tests/ui.cjs
TZMT_TEST_BASE=http://127.0.0.1:8082 node /tmp/tzmt-j62-tests/cancel.cjs
TZMT_TEST_BASE=http://127.0.0.1:8082 node /tmp/tzmt-j62-tests/failures.cjs
```

Папки тестовых изображений должны быть доступны для записи пользователю PHP.
PHP-помощники отказываются работать с другим префиксом или без явного маркера.
Подготовка скриптов сама по себе ничего не устанавливает и не меняет на сайте.
