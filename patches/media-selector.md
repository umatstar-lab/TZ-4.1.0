# Выбор Gallery / Flipbook в TZ Portfolio 4.1+

Полные установочные дополнения (обновлять поверх установленных, без удаления):

- `gallery_content_addon_v2.1.5_media_selector.zip` — через менеджер дополнений Portfolio.
- `flipbook_gallery_addon_v1.0.18_media_selector.zip` — через менеджер дополнений Portfolio.
- `com_tz_media_transfer_v1.0.1.zip` — через установщик Joomla, если используется компонент переноса.

После обновления очистить кеш Joomla. В редакторе материала поле «Тип медиа»:

| Значение | Вывод |
| --- | --- |
| Без медиа (`none`) | Ни Gallery, ни Flipbook |
| Галерея / Gallery (`content_gallery`) | Только Content Gallery |
| Флипбук галерея (`flipbook_gallery`) | Только Flipbook |

Новый пункт не совпадает с отдельными дополнениями «Галерея изображений» / Grid Gallery.
Другие дополнения и типы медиа не изменены. Настройки видимости дополнения продолжают действовать.
Материалы с прежним выбором «Без медиа» теперь скрывают Gallery: для показа выбрать новый пункт «Галерея» и сохранить.
Фотографии, подписи и настройки макета сохраняются; автоматического переноса и массового изменения материалов нет.

Gallery остаётся дополнением группы content с прежней вкладкой редактирования и прежним форматом данных.
Пункт добавляется через подготовку формы Portfolio, без изменений ядра компонента и без второй пустой вкладки.
На сайте выбранная Gallery выводится стандартным блоком **Media**, как Flipbook.
В собственном макете Portfolio должен присутствовать блок Media; прежний блок контентной Gallery не дублирует его.
Flipbook проверяет выбранный тип и в резервном обработчике вывода.

Компонент переноса 1.0.1 при включённой опции активации назначения выбирает `content_gallery`.
Для этого требуется Gallery 2.1.5+; обновить дополнения перед использованием переноса.

Проверка на локальных копиях Joomla 5.4.10 и 6.2 / Portfolio 4.1.2 / PHP 8.4:
сохранение и повторное открытие выбранного типа, оба режима конструктора макета,
отсутствие дублирующихся галерей, сохранение имён файлов и подписей.
Изменения отступов/адаптивности флипбука в этот выпуск не входят: сохранено поведение 1.0.17.

Контракт обработчиков: `php tests/media-selection.php /путь/к/components/com_tz_portfolio/add-ons`.
Патчи применяются к Gallery 2.1.4 и Flipbook 1.0.17 соответственно.
