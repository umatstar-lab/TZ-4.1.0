# Flipbook 1.0.16-j6: размеры книги и стрелки при изменении окна

Полное дополнение, обновление поверх 1.0.14 или 1.0.15 без удаления.
Устанавливается через менеджер дополнений TZ Portfolio. После установки очистите
кеш Joomla и обновите страницу. Перенос в Gallery не нужен; фотографии, подписи
и настройки флипбуков остаются на месте.

## Изменение

Booklet рассчитывал процентную ширину как `parent.css('width')` — в шаблонах
с `box-sizing: border-box` в неё входят боковые поля оболочки под стрелки.
CSS ограничивал видимую книгу шириной контента, однако страницы внутри были
шире на 88 px (72 px на мобильном). Поэтому правая страница заходила под стрелку.

Первоначальный расчёт и перерасчёт после resize используют `parent.width()`:
ширину контента без полей. При resize пересчитывается также высота по заданному
соотношению сторон. На мобильном стрелки вынесены за край книги полностью,
с сохранением места для них внутри оболочки. Версии CSS/JS обновлены для кеша.
Изменены исходная и минифицированная версии библиотеки; исправления вывода
и однократной инициализации из 1.0.15 сохранены.

## Проверка

Joomla 5.4.10 / PHP 8.4.27 / Portfolio 4.1.2.
`tests/flipbook/resize.cjs`: повторное сужение/расширение без перезагрузки
1651 → 1280 → 1000 → 769 → 768 → 767 → 600 → 390 → 320 → 1651 px.
Проверяются совпадение ширины страниц и книги, обе стрелки за её краями,
размещение внутри оболочки, отсутствие горизонтального переполнения,
соотношение сторон, сохранение разворота, переход вперёд/назад после resize.
Одинаковые проверки выполняются для исходного и минифицированного JavaScript.
`tests/flipbook/pages.cjs`: все 9 книг, 156 изображений и подписей, порядок,
загрузка и перелистывание, отсутствие ошибок JavaScript и локальных ресурсов.
