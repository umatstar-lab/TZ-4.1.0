# Диагностика маркеров PHP в изображении — 1.0.8

Полное обновление `com_tz_media_transfer_v1.0.8.zip`, устанавливать поверх текущей
версии через установщик Joomla, затем обновить страницу Ctrl+F5 и повторить действие.

При срабатывании проверки сообщение содержит:

- полный серверный путь к исходному файлу;
- найденный маркер с исходным регистром (`<?php` или `<?=`);
- точные байты маркера в HEX;
- смещение в байтах от начала данных изображения, отсчёт с нуля;
- до 32 байт контекста перед маркером;
- значение/фрагмент начиная с маркера, до ближайшего `?>` в пределах 512 байт;
- явную отметку об обрезке и наличии/отсутствии `?>` в показанном фрагменте.

Бинарные и управляющие байты экранируются как `\xNN`; существующий обратный слеш
удваивается, чтобы отличать настоящий байт от текстовой записи `\xNN`.
Сообщение остаётся корректной строкой JSON даже при произвольных бинарных данных.
В админке используется `textContent` и многострочный вывод: HTML/JavaScript/PHP
из найденного фрагмента не исполняются.

Если проверка сработала на временной копии перед заменой назначения, показывается
путь её источника, а не уже удалённого временного файла `.tz-transfer-…`.
Смещение относится к данным изображения; при восстановлении из защищённой резервной
копии это смещение не включает служебный PHP-префикс оболочки резервного файла.

Найденная последовательность байт не равнозначна доказанному вредоносному коду:
короткий маркер `<?=` может случайно встретиться в сжатом бинарном содержимом PNG/JPEG.
Сообщение теперь прямо указывает эту неопределённость. Порог срабатывания и блокировка
подозрительного переноса не изменены. Исходники и данные при отказе не удаляются.
Файл пользователя `008.png` не был приложен к запросу; его содержимое не исследовалось.

Проверки на Joomla 5.4.10 и 6.2.0 / PHP 8.4.27:
точный путь, HEX и смещения, граница 65536-байтного буфера, короткий/длинный фрагмент,
произвольные бинарные байты и валидный JSON, сообщение в UI при неудавшемся перемещении,
отсутствие исполнения HTML из фрагмента, отсутствие изменений фото и метаданных.
На Joomla 5.4 также повторены копирование, перемещение и откат из Grid в обе галереи.

Тесты: `diagnostics.php`, `diagnostic-ui.cjs`, `diagnostic-file.php`.
PHP-помощник меняет только специально подготовленный тестовый файл; запускать
тестовые фикстуры на рабочем сайте нельзя.
