# TZ Media Transfer 1.0.9: проверка изображений и пропуск ошибок

## Изменения

В 1.0.8 совпадение трёх байтов `<?=` в сжатых данных изображения останавливало
перенос. Теперь фрагмент разбирается штатным PHP Tokenizer с TOKEN_PARSE без
исполнения. Учитываются границы строк, комментариев и закрывающего тега.
Случайный бинарный фрагмент, не образующий PHP-код, не считается вставкой.
Синтаксически корректный PHP блокируется, но сообщение не утверждает, что
сам факт наличия кода доказывает его вредоносность.

Для PNG дополнительно проверяются сигнатура, IHDR, критические блоки, порядок
IDAT/PLTE, CRC каждого блока, полный zlib-поток, размеры и фильтры строк, IEND
и отсутствие хвоста. Поддерживается Adam7. Предел распакованных данных —
512 МиБ. Проверка потоковая; изображения не перекодируются.
Это не полноценный антивирус и не доказательство отсутствия всех видов угроз.

Ошибка отдельного файла переводит операцию в сохраняемое состояние `file_error`.
В окне есть «Отменить», «Пропустить файл», «Пропустить все». Последняя кнопка
применяется только к ошибкам файлов текущей операции, а не копирует подозрительные
файлы и не пропускает все оставшиеся корректные изображения.

Незавершённые записи текущего файла восстанавливаются до предложения пропуска.
Ошибка восстановления, базы, изменения материала или прав не обходится пропуском.
Пропущенные исходники и подписи не удаляются при перемещении. Отмена сохраняет
уже завершённые изменения; для их возврата остаётся отдельный откат.

Сохраняются общее количество, полные исходные пути и причины пропусков. Отчёт
доступен после перезагрузки через «Открыть» в журнале, при копировании и
перемещении. Включает также пропуски по решению оставить существующий файл.
Старые журналы без сохранённых путей показывают пояснение.

## Безопасность интерфейса и API

Пути, причины и фрагменты выводятся через textContent, бинарные байты экранируются.
Кнопки блокируются на время запроса. Решение содержит случайный идентификатор
актуальной ошибки; повторное/устаревшее решение отвергается. Действуют прежние
проверки CSRF, владельца операции, управления компонентом и актуальных прав
материалов, ограничение путей и symlink, расширений и резервных копий.

## Проверки

Обновление установлено штатным установщиком в изолированные Joomla 5.4.10
и Joomla 6.2.0, PHP 8.4.27, Portfolio 4.1.2. На Joomla 6 плагин обратной
совместимости отключён.

- `file-errors.cjs`: копирование/перемещение, одиночный/массовый пропуск,
  отмена в интерфейсе, устаревшие решения, сохранение исходников/подписей,
  отчёт после перезагрузки, точный откат по хешам и метаданным.
- Ошибка повреждённой миниатюры после записи оригинала: частичная запись
  отменяется до пропуска; оригинал и миниатюра остаются в источнике.
- `png-safety.php`: случайный маркер внутри корректного IDAT, метаданные,
  настоящий PHP, повреждённый CRC, хвост после IEND, неверный размер потока.
- Исходный PNG пользователя 916×1596 с Adam7 принят и скопирован с тем же
  SHA-256. Сам пользовательский файл в репозиторий и установщик не включён.
- `diagnostics.php`, `diagnostic-ui.cjs`: путь/маркер/HEX/смещение, безопасный
  вывод бинарных данных и HTML без исполнения.
- Регрессии engine, UI, inventory, grid, cancel, failures, security-api,
  security-files: перенос, совпадения, подписи, миниатюры, откат, права,
  ошибки записи, инъекции, CSRF, symlink и защищённые резервные копии.

Установщик содержит только код компонента и файлы интерфейса. Данные сайта,
оригиналы изображений, секреты, тестовые фикстуры и журналы в ZIP не входят.
Сервер обновлений сохраняет метаданные Joomla 5.4/6.x с SHA-256/SHA-512.
