# Gallery 2.1.7: адаптивное число колонок

Основа — `gallery_content_addon_v2.1.6_storage_paths_fix.zip`. Новые исходники
находятся в `gallery-addon/`; ZIP собирается его `package.py`.

Глобальные XML-поля: mt_gallery_columns_mobile/tablet/desktop, целые списки 1–10.
В статье: mt_gallery_columns_mode (global/custom) и три списка с showon.
Собственные настройки берутся из исходных attribs статьи, а глобальные — из
Registry дополнения. Это исключает подмену глобального режима объединёнными
настройками категории/меню и влияние оставшихся скрытых пользовательских значений.

PHP проверяет строгий диапазон каждого значения до вставки в CSS/JSON.
Нестандартные значения/массивы не попадают в стили. Селектор CSS ограничен ID
текущей галереи. Базовые значения 1/2/3 и медиа-пороги 768/1200 px.
Grid использует repeat(N,minmax(0,1fr)); Masonry распределяет исходные узлы
по N контейнерам колонок и перестраивается через requestAnimationFrame при resize.
Группы последовательные: DOM-порядок изображений/подписей и навигация Fancybox
сохраняются. При выключенном JavaScript остаётся CSS column-count с column-width:auto;
горизонтальная кладка — фиксированные равные ячейки; Slick получает responsive
slidesToShow. Данные, подписи, порядок и выбор медиа не переписываются.

Добавлены подписи настроек en-GB, ru-RU, uk-UA; версия ресурсов обновлена для
сброса браузерного кеша. Предыдущие языковые ключи включены в локализации,
чтобы частичный перевод новых полей не приводил к потере остальных подписей.

На изолированных Joomla 5.4.10 и 6.2.0 / PHP 8.4.27 / Portfolio 4.1.2 тест
`tests/gallery/columns.cjs` загружает конечный ZIP штатным addon.install,
проверяет версию установленного манифеста, настоящие формы и сохранённые значения.
Фикстура создаёт отдельную опубликованную статью с 20 изображениями/подписями
и категорией; настройки дополнения сохраняются и восстанавливаются в finally.

Проверены:

- три глобальных списка 1–10 и сохранение нового значения;
- все четыре типа на ширинах 390, 767, 768, 1199, 1200, 1440 px;
- фактическое число столбцов кладки, CSS grid и responsive Slick;
- сохранность всех 20 изображений и отсутствие горизонтальной прокрутки;
- собственные 3/6/10 и сохранённые через форму 1/3/8;
- возврат к глобальным значениям при оставшихся своих числах;
- безопасные значения 1/2/3 при некорректном содержимом параметров;
- украинская подпись в Fancybox, открытие/закрытие, отсутствие ошибок JS.

Обычная CSS-кладка может использовать меньше непустых колонок при балансировке
карточек. Браузерная проверка обнаружила 5 вместо 6 при 20 фотографиях; группировка
исправляет именно этот случай, и тест проверяет координаты карточек, а не только CSS.

Исходные каталоги тестовых сайтов ранее были скопированы от root. Для штатного
обновления исправлен только владелец тестовых файлов на www-data. Установщик
Portfolio и ядро Joomla не изменялись; временная трассировка полностью удалена.
