# TZ Portfolio 4.1.2: выбор одной статьи и отключение автоподсказок

Основа — предоставленный архив разработчика `tz_portfolio_tz-portfolio.v4.1.2.zip`.
Результат — `tz_portfolio_tz-portfolio.v4.1.2-fixed.zip` в корне репозитория.
Версия компонента остаётся 4.1.2. Установка выполняется штатным установщиком Joomla с последующим мастером TZ Portfolio.

## Выбор статьи

В 4.1.2 сохранились прежние ошибки: поле одиночной статьи зависело от jQuery на странице менеджера меню; окно закрывалось старым jQuery-вызовом; форма поиска направлялась в `com_tz_portfolio_plus`.

Обработчик перенесён на DOM API и Bootstrap 5. Он устанавливает ID и заголовок, отправляет событие change, корректно закрывает окно даже во время анимации открытия и поддерживает очистку. Форма поиска использует `com_tz_portfolio` и сохраняет callback. Дополнительно исправлено экранирование значения выбранного заголовка: кавычки больше не обрезают название при повторном открытии меню и не становятся HTML-разметкой.

## Подсказки

Автозапуск Intro.js отключён централизованно в адаптере TZ Portfolio. Просмотр страниц больше не зависит от существования и доступности для записи `cache/introguide.json`. Подсказки доступны только по явному нажатию кнопки Intro Guide. Обновлены оба варианта адаптера (основной и legacy vendor) и их исполняемые копии. В реестре ресурсов указан новый файл `introguide.manual.min.js`, чтобы не использовать прежний закэшированный автозапуск.

Глобальная система обучающих туров Joomla не изменяется. Окно на присланном скриншоте относится к Intro.js компонента, а не к глобальной системе Joomla.

## Проверки

Чистая Joomla 6.2.0 / PHP 8.4.27 / MariaDB 11.4. Установлен именно итоговый ZIP, пройден штатный мастер. Через Chromium проверены создание статьи, действия в списке, поиск и выбор в окне, закрытие и очистка поля, сохранение неопубликованного пункта меню и повторное открытие с той же статьёй. Проверен заголовок с украинским текстом, двойными кавычками, амперсандом и апострофом.

Отсутствие автоподсказок проверено на страницах дополнений, статей, категорий, полей и тегов при первом и повторном посещении. Настоящая кнопка ручной помощи открывает и закрывает тур; ошибок JavaScript нет. Глобальный приветственный тур Joomla блокируется только в тестовом браузере, чтобы он не перенаправлял сценарий на главную панель.

Пройдено повторное обновление поверх установленного компонента; содержимое тестовых записей статей и меню до/после совпало. Пройдены четыре HTTP-проверки сайта, синтаксис изменённых PHP и JS, CRC ZIP и пробное применение патча.

Все изменения ограничены 8 файлами: поле и окно выбора статьи, адаптеры подсказок и реестр ресурсов. Остальные файлы из нового архива сохранены без изменений. В частности, контроллер лицензирования, константы активации и манифест побайтно совпадают с 4.1.2 разработчика. Старые изменения HTTP/активации из 4.1.0 не переносились. Настоящий ключ пользователя не запрашивался; активация лицензии не тестировалась.

Патч `tz-4.1.2-menu-tours.patch` применяется из корня распакованного исходного пакета командой `patch -p1`. Браузерный тест: `node tests/tz-4.1.2/admin-ui.cjs` из корня репозитория, на подготовленном тестовом сайте `http://127.0.0.1:8082` с локальными учётными данными из `/workspace/tz-4.1.2/runtime/.env`. Тест создаёт собственные статьи и неопубликованные пункты меню. Значения паролей в репозиторий не включены.
