# Перенос Grid Gallery 1.0.13 → Gallery / Flipbook

Установочный архив: `com_tz_media_transfer_v1.0.7.zip`. Полное обновление поверх
текущего компонента через установщик Joomla. Требуется установленный Portfolio 4.1+
и совместимое дополнение назначения Content Gallery или Flipbook.

Проверен присланный ZIP `grid_gallery_addon_grid-gallery-addon.v1.0.13.zip`:
старый `admin/models/grid_gallery.php` сохраняет `data`, `title`, `featured`
в `media.grid_gallery`, файлы — в `images/tz_portfolio_plus/grid_gallery/ID`.

## Изменения

- Источник «Грид галерея — Grid Gallery» доступен без провайдера старого дополнения
  для Portfolio 4.x. PHP-код Grid 1.0.13 при поиске и переносе не исполняется.
- Читаются данные **материалов уже установленного Portfolio 4.1+**. Компонент
  не заменяет установку/миграцию самих материалов из Portfolio+ 2.7.3.
- Файлы ищутся в трёх корнях: `com_tz_portfolio`, `tz_portfolio`, `tz_portfolio_plus`.
- Без совместимого установленного провайдера Grid доступен только как источник.
  Запись в неподдерживаемое старое дополнение сервер отклоняет.
- В таблице всегда три группы: Флипбук, Галерея, Грид галерея. В каждой два
  столбца «Изображения» / «Подписи». До поиска шесть прочерков, после — реальные
  количества существующих файлов и их подписей. Поиск запускается вручную.
- Копирование и перемещение в Content Gallery или Flipbook используют прежние
  диалоги совпадений, независимые политики подписей, отмену и журнал отката.
- Дополнительно исправлено заполнение отсутствующих миниатюр назначения, если
  оригинал уже совпадает по содержимому. Существующие отличающиеся миниатюры
  при сохранении того же оригинала не перезаписываются.
- Защита версии 1.0.6 и XML совместимости с Joomla 6.x сохранены.

## Порядок действий на сайте

1. Установить Portfolio 4.1.2 и проверить, что материалы и данные Grid перенесены.
2. Установить совместимые Gallery / Flipbook и компонент переноса 1.0.7.
3. «Откуда» → «Грид галерея», «Куда» → нужное дополнение, «Найти изображения».
4. Для первого переноса выбрать **Копировать** и отметить материалы. При необходимости
   включить переключение основного вывода на назначение. Начать копирование.
5. Проверить фотографии, подписи и вывод на сайте до удаления старого Portfolio+.

Удаление Portfolio+ 2.7.3 стирает `images/tz_portfolio_plus`. Новые копии в Gallery
и Flipbook сохраняются в `images/com_tz_portfolio`.

## Проверки

На Joomla 5.4.10 и 6.2.0 / PHP 8.4.27 / Portfolio 4.1.2:

- источник Grid без современного установленного провайдера;
- точный формат данных из Grid 1.0.13, порядок, Unicode/кавычки и избранное;
- три исходных фотографии из трёх разных корней + отсутствующая запись;
- Grid → Gallery и Grid → Flipbook в режимах копирования и перемещения;
- совпадения оригинала и подписей, заполнение миниатюр и переключение типа медиа;
- при копировании исходные данные не изменены; при перемещении отсутствующая
  запись в источнике сохраняется;
- полный откат восстанавливает метаданные и контрольные суммы файлов;
- три группы столбцов, прочерки до поиска и реальные количества после него;
- регрессионные проверки поиска и существующих направлений; на Joomla 5.4 также
  полный UI и негативные тесты API безопасности.
