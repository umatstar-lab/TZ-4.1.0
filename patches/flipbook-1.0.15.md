# Flipbook 1.0.15-j6: восстановление вывода в Portfolio 4.1.2

Исходник: присланное дополнение `flipbook_gallery_addon_v1.0.14_j6_tzportfolio407_header_arrows_fix.zip`.
Проверено на Joomla 5.4.10 / PHP 8.4.27 / TZ Portfolio 4.1.2.

## Установка

В новом TZ Portfolio откройте менеджер дополнений → Установить/обновить,
загрузите `flipbook_gallery_addon_v1.0.15_tzportfolio412_fix.zip` поверх 1.0.14.
Предварительно сделайте резервную копию сайта. Удалять старое дополнение не нужно.
Очистите кеш Joomla и обновите страницу сайта. Тип медиа материалов оставьте
«Флипбук галерея», дополнение — включённым, показ флипбука — включённым.
Миграционный скрипт не запускайте: фотографии и подписи остаются во флипбуке.

## Причина и изменение

1. В 1.0.14 обработчики стандартного вывода медиа возвращали `null`.
   Рендеринг был перенесён в `onContentDisplayArticleView`, но Portfolio 4.1.2
   вызывает это событие для статьи только при отключённом конструкторе макета.
   Конструктор подключает через это событие только контентные дополнения,
   тогда как флипбук относится к `mediatype`. Результат: нет разметки и ресурсов.
   Восстановлен вывод через `onContentDisplayMediaType` для активного типа
   `flipbook_gallery`. Дополнительный обработчик и защита от дубликатов сохранены.
   Штатный код 1.0.14 по-прежнему размещает книгу после текста статьи.
2. View и шаблон запускали `.booklet()` дважды. Первый запуск использовал
   несуществующее общее меню `#flipbook-gallery-menu`; повторный пытался уничтожить
   неполностью инициализированный экземпляр и выдавал ошибку `null.find`.
   Инициализация осталась в шаблоне, один раз для каждого уникального ID книги.
3. Исправление 1.0.14 устанавливало стрелкам `z-index: 2`, ниже страниц книги
   с уровнями 20–30. Возвращён уровень 40 **внутри изолированного контейнера**;
   ограничения относительно шапки сайта сохранены. CSS получает версию 1.0.15
   для обновления браузерного кеша.

Форматы данных, пути изображений, загрузчик, подписи и настройки не менялись.
SQL-конвертации и переноса в Gallery в этом архиве нет.

## Проверка

До исправления: на локальной копии с исходными данными 1.0.14 не выводил книгу.
После исправления `tests/flipbook/pages.cjs` проверяет все 9 опубликованных
флипбуков: 156 изображений с исходными именами, порядок, точные подписи,
один экземпляр книги, реальный щелчок по стрелке и изменение номера разворота.
Проверяются HTTP 200, загрузка изображений, отсутствие ошибок JS и локальных
ресурсов. Изображения локального стенда синтетические; имена и подписи взяты из
присланной базы. Данные сайта и сама база в репозиторий не включены.
