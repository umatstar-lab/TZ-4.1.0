# Перенос 1.0.5: поиск по существующим файлам

Полное обновление `com_tz_media_transfer_v1.0.5.zip` устанавливается поверх
текущего компонента через установщик Joomla. Обновлять дополнения не требуется.
Вверху экрана показана версия 1.0.5; после установки обновить страницу Ctrl+F5.

- При открытии выполняется `catalog`: список материалов и дополнений без подсчёта фотографий.
  Итоги пустые, четыре ячейки количества в каждом материале содержат прочерки.
- Кнопка «Найти изображения» вызывает новый поиск файлов на сервере. Поиск
  не использует прошлые результаты; старые значения очищаются перед запросом.
- Количества изображений включают только связанные с материалом существующие
  читаемые оригиналы. Подписи считаются только у найденных фотографий.
  Отсутствующий оригинал и его подпись в статистику не входят.
- Две группы колонок по выбранным дополнениям, обычно «Флипбук» и «Галерея»:
  в каждой «Изображения» / «Подписи». Убран столбец «Проверка» и текст «Недоступно».
- Пути Flipbook и Gallery: `images/com_tz_portfolio`, затем `images/tz_portfolio`,
  затем `images/tz_portfolio_plus`, с проверкой каждого оригинала.
- При подготовке новой операции обрабатываются только реально существующие
  файлы. Старые отсутствующие записи не блокируют остальные изображения;
  их метаданные в источнике не удаляются, в том числе в режиме перемещения.
  Если нет ни одного доступного оригинала, операция не запускается.
- API отправляет `Cache-Control: no-store`, а повторный поиск сбрасывает
  файловый stat-кеш перед проверкой путей.

Проверено на локальной Joomla 5.4.10 / Portfolio 4.1.2: отсутствие автопоиска,
пустые итоги и прочерки, обе группы количеств, исключение отсутствующего файла
и его подписи, изменение счётчиков при исчезновении и возвращении файла,
перенос оставшихся трёх файлов при одной отсутствующей записи, откат и массовый
выбор. Также прошли проверки движка копирования/перемещения в обоих направлениях,
конфликтов, отката, подписей с HTML, интерфейса и CSRF.

Тесты нового поиска: `tests/media-transfer/inventory.cjs` и `inventory-file.php`.
PHP-помощник только для подготовленного изолированного стенда; он временно
убирает и возвращает один тестовый оригинал. На рабочем сайте тест не запускать.
