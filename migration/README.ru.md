# Перенос Plus 2.7.3 → Portfolio 4.1.2

Для Joomla 5.4.10. PHP **8.4.1 или новее нужен и сайту, и команде PHP**.
Это набор для распаковки, **не единый установочный ZIP Joomla**.
Внутри `installers/` — два ZIP для установки через Joomla,
`tools/` — скрипт для запуска через PHP CLI.

Gallery — дополнение **2.1.4 для компонента 4.1.2**, а не дополнение версии 4.1.2.

## Что переносится

Компонент 4.1.2 использует существующие таблицы `#__tz_portfolio_plus_*`.
Материалы, категории, ID, связи, тексты и языки остаются на месте.
Скрипт преобразует галереи в материалах, копирует их изображения на том же сервере,
сохраняет подписи и порядок, обновляет ссылки существующих пунктов меню.
Файлы с сервера скачивать и загружать сюда не нужно.

Для присланной базы: **9 опубликованных флипбук-галерей, 156 фотографий и
156 подписей, 9 пунктов меню**. Четыре материала в корзине исключены.
Материалы корзины не преобразуются, их фотографии не копируются, ссылки на них
не переключаются. Поскольку таблицы общие, исходные записи останутся в корзине;
скрипт не удаляет их и не восстанавливает в опубликованных материалах.

В материале 6 уже есть Gallery с теми же 21 файлами и пустыми подписями.
Скрипт использует существующую запись, восстанавливает подписи и порядок из
флипбука, без дубликатов. Разные непустые подписи или дополнительные фотографии
в Gallery считаются конфликтом: перенос останавливается для ручного разбора.

## Установка и запуск на сервере

1. Сделайте полную резервную копию базы и файлов сайта. Сначала выполните
   процедуру на копии сайта. На время применения включите режим обслуживания
   и прекратите редактирование материалов.
2. Переключите сайт на PHP ≥ 8.4.1 и проверьте `php -v` для CLI.
3. Через Joomla → Система → Установка расширений установите архив
   `tz_portfolio_tz-portfolio.v4.1.2-fixed.zip` из этого репозитория.
   Завершите мастер компонента **без демонстрационных данных**.
   **Не удаляйте Plus 2.7.3 перед установкой:** старый деинсталлятор может удалить
   общие таблицы. Не запускайте старый компонент после начала переноса.
4. В менеджере дополнений **нового** Portfolio установите
   `gallery_content_addon_v2.1.4_tzportfolio_4.1_layout_fix.zip`; включите Gallery.
5. Положите `migrate-flipbook.php` за пределами публичного каталога сайта.
   Создайте там же отдельную закрытую папку для журнала отката. Скрипт читает
   подключение к базе из `configuration.php`; передавать пароли не требуется.

Пример: сайт `/home/account/public_html`, инструмент `/home/account/tools`,
закрытый журнал `/home/account/tz-backups`. Подставьте свои пути и имя PHP 8.4.
Запускайте от пользователя сайта, имеющего права чтения и записи изображений.

```sh
mkdir -p /home/account/tz-backups
chmod 700 /home/account/tz-backups
php /home/account/tools/migrate-flipbook.php --site=/home/account/public_html
```

По умолчанию это **только проверка**, база и изображения не изменяются.
В отчёте должны быть `ready: true`, `galleries: 9`, `photos: 156`,
`captions: 156`, `trash_skipped: 4`, пустые `missing_files` и `conflicts`.
Числа относятся к присланному дампу; на изменившемся сайте они могут отличаться.

Применение:

```sh
php /home/account/tools/migrate-flipbook.php --site=/home/account/public_html --apply --backup-dir=/home/account/tz-backups
```

В конце появятся `status: committed` и путь `backup`. Сохраните этот путь.
Если какого-либо оригинала нет или файл назначения отличается, применение
останавливается до изменения материалов. Проверяются контрольные суммы копий.
Исходные фотографии и поле `media` флипбука сохраняются.
Файлы копируются из `images/tz_portfolio_plus/flipbook_gallery/ID/` в
`images/tz_portfolio_plus/gallery/ID/`, а также связанные миниатюры из `resize`.
Поддерживается аналогичная конвертация активных `grid_gallery`, кроме корзины.

Материал получает тип медиа «Без медиа», потому что Gallery — контентное
дополнение. Это предотвращает повторный вывод флипбука. Настройки Gallery
материала: masonry, ширина 400, оригинальный размер, подпись под фотографией.
Другие настройки материала сохраняются. Общие настройки дополнения не меняются.

После применения очистите кеш Joomla и кеш шаблона. Проверьте все 9 страниц
меню, подписи, открытие lightbox и мобильную ширину, затем выключите обслуживание.
Стили и модули от старого Plus не преобразуются автоматически: они требуют
совместимых версий для 4.x. Старые расширения не удаляются этим инструментом.

## Откат

Включите обслуживание. Используйте **точный** путь журнала из успешного отчёта:

```sh
php /home/account/tools/migrate-flipbook.php --site=/home/account/public_html --rollback=/home/account/tz-backups/tz-migration-ДАТА-ИДЕНТИФИКАТОР.json
```

Откат восстанавливает изменённые поля материалов, Gallery и ссылок меню.
Если эти поля после миграции уже редактировали, скрипт откажется их перезаписывать.
Копии фотографий остаются на диске; оригиналы не удалялись.
Откат не отменяет установку компонента 4.1.2: для полного возврата сайта нужна
полная резервная копия, сделанная перед установкой.

## Проверка реализации

`tests/migration/verify.php` — интеграционные проверки на отдельном префиксе
`migration273_`. Проверяются точные подписи и порядок из присланного дампа,
контрольные суммы файлов, неизменность корзины и связей, повторный запуск,
откат, защита последующих правок, отсутствие оригинала и конфликт файла.
Фотографии в локальном тесте синтетические, с реальными именами из базы:
наличие и содержимое оригиналов на вашем сервере проверяет предварительный запуск.
Дамп базы, конфигурация и подписи пользователя в репозиторий не включены.

Дополнительно проверена штатная установка Portfolio 4.1.2 на **Joomla 5.4.10 /
PHP 8.4.27** поверх таблиц из дампа: поля материалов установщик не изменил.
Браузерные проверки `tests/migration/gallery-pages.cjs` прошли для всех девяти
материалов: 156 изображений, порядок и подписи, шаблон страницы, masonry, lightbox,
мобильная ширина и отсутствие ошибок локальных ресурсов/JavaScript.
