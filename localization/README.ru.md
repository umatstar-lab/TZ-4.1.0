# Локализация TZ Portfolio: русский и украинский

Три независимых установочных ZIP для **менеджера расширений Joomla**.
В каждом находятся оба языка: `ru-RU` и `uk-UA`.

| Пакет | Назначение |
|---|---|
| `tz_portfolio_localization_ru_uk_v1.0.0.zip` | Portfolio 4.1.2: админка, сайт, девять штатных дополнений (Vote, Image, Profile, шесть типов дополнительных полей), пять модулей, системный плагин и стиль System |
| `tz_flipbook_localization_ru_uk_v1.0.0.zip` | Flipbook Gallery 1.0.19 |
| `tz_gallery_localization_ru_uk_v1.0.0.zip` | Content Gallery 2.1.7, включая адаптивные колонки |

## Установка

1. Сначала установите сам Portfolio и нужные дополнения.
2. В Joomla откройте **Система → Установка расширений → Загрузить файл пакета**.
3. Загрузите нужные ZIP по очереди. Устанавливать их в менеджере дополнений
   TZ Portfolio не требуется: это отдельные файловые пакеты переводов Joomla.
4. Выберите русский или украинский язык в настройках Joomla/пользователя и
   обновите страницу. Языковые пакеты самой Joomla должны быть установлены;
   эти ZIP переводят только Portfolio и перечисленные расширения.

Переводы не переключают язык сайта автоматически, не устанавливают сами
компоненты и не меняют фотографии, материалы, меню, настройки или английские
файлы. Повторная установка обновляет только перечисленные RU/UK-файлы.
Существующие файлы перевода с теми же именами заменяются. Удаление пакета
удаляет его переводы, но не компонент, дополнения или данные сайта.

## Результат сверки

Все **27 английских INI** из language.zip побайтово совпали с соответствующими
оригиналами Portfolio 4.1.2, Flipbook 1.0.19 и Gallery 2.1.7.
В архиве `setup/packages/styles/system.zip` имеется ещё одна копия языка System:
ключи и значения совпадают с распакованной копией; отличаются только ссылки
в комментариях. Её перевод устанавливается один раз в рабочий каталог стиля.

В русской и украинской локализациях Gallery наборы ключей были полными (70),
но по **28 значений оставались английскими**. Они переведены заново вместе
с остальными файлами. Переведены все **1697 исходных ключей** в 27 файлах,
соответствующие 1453 уникальным английским значениям. Прочие предоставленные
расширения не содержали RU/UK-файлов — они созданы.

Учтены особенности оригинала:

- один повторный ключ ширины Flipbook с разными значениями: сохранено последнее
  значение, как при штатном чтении оригинала;
- два старых ключа с пробелами (`TAGGED UNDER`, `ADDITIONAL INFO`) сохранены;
- добавлены 17 совместимых старых `COM_TZ_PORTFOLIO_PLUS_*` языковых ключей,
  найденных в формах/коде и имеющих современное соответствие;
- для независимых пакетов Gallery/Flipbook добавлен перевод старого пункта
  наследования от категории;
- исправлена неточная английская формулировка ошибки миниатюры изображения,
  в которой оригинал ошибочно упоминал аудиозапись;
- сохранены форматные параметры `%s`, `%d`, `%1$s` и нестандартные исходные
  `%1s`, HTML-теги/атрибуты, ссылки, даты PHP и названия брендов.

Новых PHP-скриптов, SQL, JavaScript и обработчиков установки в ZIP нет.
Установка выполняется штатным файловым адаптером Joomla по фиксированным
относительным путям. Каждый манифест перечисляет конкретные INI-файлы;
операций над каталогами изображений нет.

## Проверки

Проверены **Joomla 5.4.10 и 6.2.0 / PHP 8.4.27** с Portfolio 4.1.2.
На Joomla 6 плагин обратной совместимости отключён.

- установка и повторная установка всех трёх пакетов штатным установщиком;
- загрузка каждого ZIP через обычный менеджер расширений в авторизованной
  браузерной сессии на обеих версиях Joomla;
- чтение всех 98 устанавливаемых INI-файлов штатным `LanguageHelper` и
  `Language::load`, проверка каждого ключа и значения, контрольных сумм файлов;
- отсутствие пропущенных переводов, неверных форматных параметров, изменения
  HTML/URL, смешения русских и украинских букв; UTF-8 без BOM;
- целостность ZIP и соответствие всех путей манифестам. Сборка воспроизводимая.

94 INI-файла основного пакета включают копии языков модулей/плагина в штатных
языковых каталогах Joomla и в собственных каталогах расширений: это обеспечивает
загрузку и на сайте, и в админке. У Gallery и Flipbook — по два файла.

Исходники и сверка: `source/`, `translations/reviewed.tsv`,
`translations/source-values.json`, `audit.json`.
Все переводы подготовлены локально; внешнему сервису полный набор строк не
передавался. В исходниках сохранены английские файлы для воспроизводимой сверки;
в устанавливаемые ZIP они не входят.

Сборка и проверки в подготовленной тестовой среде:

```
python localization/validate.py
python localization/audit_originals.py
python localization/test.py migration273-web-1
python localization/test.py tz412-web-1
node localization/test-upload.cjs
TZMT_TEST_BASE=http://127.0.0.1:8082 node localization/test-upload.cjs
python localization/audit_originals.py
```

Изменять исходники программы для установки переводов не нужно.
